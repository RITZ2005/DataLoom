Example: Embedded Chatbot Widget

This is a simple HTML page demonstrating how to embed the chatbot widget.

Note: Replace YOUR_DOMAIN and YOUR_COLLECTION_ID with your actual values.

Method 1: Floating Widget (Recommended)

Add this script tag before the closing </body> tag:

<script src="http://YOUR_DOMAIN/chatbot-widget.js" 
        data-collection-id="YOUR_COLLECTION_ID" 
        data-base-url="http://YOUR_DOMAIN"></script>

Method 2: Iframe Embed

Add this iframe code anywhere in your HTML:

<iframe src="http://YOUR_DOMAIN/#/embed-chatbot/YOUR_COLLECTION_ID" 
        width="400" 
        height="600" 
        frameborder="0" 
        style="border-radius: 12px; box-shadow: 0 4px 20px rgba(0, 0, 0, 0.15);"></iframe>
